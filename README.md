# MDS Licensing

Companion plugin for **MDS Release Manager** (and optionally **MDS Metadata**) providing end-to-end **Sync Licensing, Rights Clearance, Split Sheet Agreements, and Content ID Allowlist** workflows for independent artists, record labels, music publishers, and corporate rightsholders.

## Features

- **Sync Licensing & Music Supervisor Hub:** Per-release/track One-Stop & Easy-Clear status, Master % & Publishing % ownership, Direct Clearance Contact, BPM, Key, Moods, Instrumentation, Stems/Alt-Versions checklist, **DISCO.ac-ready CSV**, and **Broadcast Cue Sheet** (RapidCue / ASCAP / BMI / SoundMouse) exports.
- **Cover Song Mechanical Licensing & Sample Clearance Ledger:** Built-in **2026 US CRB Phonorecords IV statutory mechanical royalty calculator** (`$0.131`/track or `$0.0252`/min over 5 min), HFA/Songfile/Easy Song tracking, optional **Easy Song B2B API** connector, and a **Sample & Interpolation Clearance Ledger**.
- **Printable Split Sheet Agreements:** Auto-generates clean, print-ready Split Sheet Agreements (pulling writer/publisher splits from `mds-metadata` when active, or standalone) with signature blocks.
- **YouTube / Meta Content ID Allowlist Ledger:** Tracks licensed client/brand/creator YouTube channels & video IDs exempted from Content ID claims and exports distributor/CMS allowlist CSVs.
- **Frontend Sync Catalog & Quote Request Block (`mds-lic/sync-catalog`) + `[sync-catalog]` Shortcode:** Filterable One-Stop / Mood / BPM licensing showcase with built-in Sync Quote Request modal & REST submission.
